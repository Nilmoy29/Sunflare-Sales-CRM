## Key Lessons Learned

1. **Schema-first epics pay off for geospatial work.** 6.1 RLS + GiST index + unique assignment index meant 6.2–6.5 added RPCs and UI only — no mid-epic schema surprises.

2. **Dedicated admin territory page beats embedding draw on knock map.** 6.2 explicitly avoided `/admin/map` — draw tool and knock/heatmap concerns stay isolated.

3. **Date semantics must be named once and reused everywhere.** `formatSydneyDateString(new Date())` for assignments, rep overlay, and admin filters — document in every story touching `assigned_date`.

4. **Rep map hooks need loading gates when caching across shift boundaries.** 6.4 review caught stale polygon flash on shift restart — same class of bug as 3.1 stale pins and 5.5 hook stale data.

5. **Client-side heatmap on existing pin data is sufficient v1.** 6.5 shipped without PostGIS aggregation — separate non-clustered GeoJSON source + Mapbox `heatmap` layer satisfies FR22 and NFR1.

6. **Story "do NOT" lists are load-bearing.** Prevented heatmap in 6.2–6.4, territory overlay on admin map, and `ST_Contains` server gate on knocks — kept reviews fast and scope tight.
